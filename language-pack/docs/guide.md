# 从这里开始

pokeldn 通过本地无线通信与 Switch 或 Switch 2 上的宝可梦游戏进行交换。接在 USB 上的 ESP32 开发板作为射频。主机上不需要安装任何东西。

## 需要准备什么

- 一块带 USB 串口桥的经典 ESP32 开发板（ESP32-D0WD、WROOM-32E），或通过原生 USB 端口连接的 ESP32-S3、ESP32-C3、ESP32-C6。它们都使用 2.4 GHz。不支持 S2 开发板。Seeed Studio XIAO ESP32C3 需要装上随附的天线；XIAO ESP32C6 使用内置天线。
- 一根 USB 数据线。只能充电的线不会显示端口。
- 从你自己的 Switch 提取的 `prod.keys`。应用只会索取一次。
- “游戏”页面上的七款游戏之一。

## 首次运行

1. 开发板：插上开发板，在“无线通信”旁选择“安装”。应用会识别芯片、写入固件，然后自行检查开发板。当开发板有响应时，页面顶部会显示“已是最新版本”。
2. 游戏：选择一款游戏和一个工具。“主机”类工具会等待你的 Switch 加入；“加入”类工具会找到 Switch 自己发起的搜索。
3. 要送出的宝可梦：搜索一个种类，然后点击“生成”。PKHeX 会为该游戏生成一只合法的宝可梦，其初训家为“设置”中的训练家。
4. 开始之前，“会话”面板会列出仍然缺少的内容，并提供修复按钮。按“主机上的操作”下的步骤操作，然后点击“开始”。

带两个 USB 端口的 ESP32-S3、C3 或 C6 开发板只能通过标有 USB 的端口与应用通信。通过另一个端口（COM 或 UART）刷写虽然可行，但之后开发板永远不会响应；“开发板”页面会说明这一点。同时插着多块开发板时，“使用这块开发板”用于选择会话使用的那一块。

种类下方的“更多选项”可设置性格、特性、性别、携带道具、精灵球、亲密度、个体值和努力值（《Let's Go》中为觉醒值，《传说 阿尔宙斯》中为奋斗等级）。留空的字段保持随机。列表中只包含该种类在该游戏中合法可有的内容；若组合被 PKHeX 判定为不合法，“生成”会拒绝并给出原因（“设置”→“高级设置”→“允许不合法宝可梦”会同时解除这两项）。只有当“设置”中的“你的训练家”就是主机的玩家时，交换来的宝可梦才会保留亲密度；《火红／叶绿》每次交换都会把它设为 70。

宝可梦下方的“添加交换”可为同一次会话排队最多六项；每完成一次交换就会送出下一项。它在每个交换工具中都会显示。每次交换收到的宝可梦都会单独存成一个文件。

可以把文件拖到应用上：把宝可梦文件或 Showdown 队伍（`.txt`）拖到某项交换上会填入该项，拖到“添加交换”上则每个文件排队一次交换。把礼物文件拖到“礼物”卡片上会打开它，把 `.bin` 拖到“开发板”页面的“固件”卡片上则会在确认后安装它。

主机发送给你的宝可梦会保存在 `Documents/pokeldn/Received`，并复制一份到银行。用银行的加号按钮，或把文件拖到它的网格上，可以导入宝可梦文件或整个游戏存档：其中每只合法的宝可梦都会存入银行一次，文件本身保持原样。来自较早游戏的宝可梦会按 HOME 的传入方式，留下携带道具并遗忘秘传招式。

## 释放存储空间

“设置”→“存储”会显示可以释放多少空间。点击“清除本机文件”，再点击“清除文件”，即可删除保存的会话记录、日志、临时送出的宝可梦和未使用的已生成宝可梦。请先保存报告问题所需的记录。已收到的宝可梦、已选定的送出内容、密钥、固件和设置都会保留。清除文件前请先结束当前的运行。

## 火红／叶绿的语言

神秘礼物的“主机”卡片会显示版本和自动语言检测。请选择《火红》或《叶绿》。在游戏的“朋友”列表中选择 pokeldn 后，游戏会上报它的卡带代码；pokeldn 会在发送代码前选好对应语言的礼物脚本和 RAM 地址。两个版本都支持英语、法语、德语、意大利语、西班牙语和日语。

保存原生 `.wc3` 时，如果礼物随版本或语言而不同，应用会询问它属于哪个卡带。`.pokegift` 会保留所有变体，并在主机连接时选出正确的那一个。

“高级”中的“训练家语言”描述的是 pokeldn 自己在连接中的训练家。它不会选择主机的语言。

## 基础与高级

“基础”显示大多数运行所需的字段；每款游戏经过测试的设置会在底层应用。“高级”列出该游戏会话接受的所有选项，并带有各自的说明文字。在那里设置的值会覆盖“基础”中的字段。除非指南或问题报告要求更改，否则请勿改动。

大多数玩家从不改动的设置位于“高级”顶部，且已设置好：会话自行停止前的时限、无线频道，以及“每次重新生成 PID”。“每次重新生成 PID”会给送出的每只宝可梦一个新的 PID，让已经接收过它的存档能再次接收；如果文件的 PID 必须保留，例如配信宝可梦，请关闭它。

## 你自己的宝可梦文件

“或使用宝可梦文件”接受从 PKHeX 导出的文件。应用会用 PKHeX 检查它，并在送出前显示它是否合法。不合法的宝可梦在被绘制时可能使对方游戏崩溃。

## 神秘礼物

每个神秘礼物工具都从四个选项开始。“使用预设”会发送现成的礼物。在《剑／盾》中，“官方活动”会列出真实的配信卡片（宝可梦、道具、服装、对战点数），并配有搜索框。“自行创建”会打开一个表单：在《火红／叶绿》中是带文本、发放者和内容的神秘卡片、神秘新闻，或你自己的 ARM 代码；在《剑／盾》中是宝可梦、蛋、道具或对战点数。“打开文件”会发送别人分享的 `.pokegift`、用于《火红／叶绿》的 `.wc3` 卡片，或用于《剑／盾》的 `.wc8` 卡片。

“自定义”会把预设变成可以修改的表单。“发送前确认”会显示主机会得到什么、何时发生，以及适用于哪些卡带；若存在问题，那里会以红字显示，且“开始”保持不可用。

在《火红／叶绿》中，“游戏强化”可改变游戏的运行方式，例如加速或加入跟随的宝可梦。选中强化项并发送，它们会立即生效，并在游戏重启时停止。若想在重启后再次使用，请启用“保存强化供之后使用”，发送强化项，然后发送“妈妈恢复你的强化”。每次重启后，到真新镇家中与妈妈对话即可重新开启。跟随的宝可梦始终会被保存。接收另一张神秘卡片会替换妈妈的礼物；再次发送该脚本，即可恢复她开启已保存强化的能力。

“读取存档”会在会话日志中显示结果。训练家 ID（TID）是训练家卡片上的编号；里 ID（SID）通常不显示。队伍读取会显示你最后一次保存的队伍中的每只宝可梦，以及它的性格、六项个体值（0 到 31 的单项数值）和努力值（训练点数）。这些工具不会改动你的存档和神秘卡片。训练家详情和队伍工具还会把读取到的数据另存一份到 Received。

主机代码会在接收礼物时在游戏内运行。“离线检查”会先在模拟主机上运行它；会让菜单卡死的代码会被拒绝。原生代码可以改变正在运行的游戏或其存档。只发送你已检查过来源和行为的代码。

“保存礼物文件”会把选中的礼物保存下来，以便重复使用或分享。它无需开发板即可使用。

在《火红／叶绿》中，“你的存档”会把整个存档从 Switch 复制到这台电脑，或把存档写回去。“从 Switch 备份”会让主机的存档保持原样；副本会出现在“你的存档”中，并以训练家命名。“将存档写入 Switch”会把选中的存档写在主机自己的存档旁边；主机会校验每个部分，加载并保存，若出现问题则保留它的旧存档。请先备份主机。还原会等到 PKHeX 判定整支队伍都合法，或等到你开启“仍要还原”后才进行。

“你的存档”保存在 `Documents/pokeldn/Saves`。可以给存档改名以便区分，把它导出为 `.sav` 供模拟器或 PKHeX 使用，也可以用 + 添加一个 `.sav`，或把它拖到卡片上。“查看与编辑”会显示训练家、队伍和 PC 盒子：可以修改名字、金钱或代币，重新排列或移除队伍中的宝可梦，添加一只为该存档的训练家生成的宝可梦，并检查某个盒子的合法性。“另存为新存档”会把结果添加在原存档旁边，原存档保持不变。

## 运行失败时

- 先停止，然后退出主机的搜索界面并重新搜索。大多数游戏会在一小段时间内保有过期的会话。
- 每次运行只改动一项。
- “设置”→“记录每次连接阶段”→“打开记录”会显示每次会话的录制内容；请把最近的一次附在问题报告中。
